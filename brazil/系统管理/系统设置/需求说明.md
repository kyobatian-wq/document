# 系统设置—站点显示配置迭代

## 已确认内容
在 DD.GG「系统管理 → 系统设置 → 站点显示配置」中加入以下四项，后台风格依据图9，客户端位置依据图2、4、6、8。

| 配置 | 参考图可见功能 | 客户端对应位置 |
|---|---|---|
| 游戏合作平台 | 默认/自定义、图片预览、上传图片、确定；JPG/PNG/SVG，建议1125×744；图片不超过2M | 首页底部游戏合作平台区域 |
| 充值合作伙伴 | 默认/自定义、图片预览、确定；建议1125×195；图片不超过2M | 游戏合作平台下方 |
| 首页底部文案 | 多行文本、保存 | 品牌版权区域下方 |
| 主媒体配置 | 序号、媒体类型、图标、媒体链接、备注、操作；新增、编辑、删除；图标建议114×114；图片不超过2M | 底部文案下方 |

## 业务目标与流程
统一维护首页底部展示素材和媒体入口，减少客户端逐项修改。操作路径：进入配置 → 修改草稿 → 校验 → 保存成功 → 客户端读取已保存配置。客户端展示顺序：游戏合作平台 → 充值合作伙伴 → 品牌版权 → 底部文案 → 主媒体图标。

## 配置规则
| 场景 | 原型行为 |
|---|---|
| 保存与重新读取 | 点击“确定”或“保存”并通过校验后保存配置；编辑不影响已保存客户端；不提供“取消修改”按钮；未保存时切换栏目或刷新页面，直接丢弃草稿并重新读取已保存配置，不弹出确认提示 |
| 默认图片 | 内置文字标识示意图，仅演示版式，正式品牌素材待提供 |
| 默认与自定义切换 | 切回默认并保存后，保留已保存的自定义图片；再次选择自定义时回显，仅上传新图片并确定保存后替换原图；未保存的替换不生效 |
| 自定义图片 | 两类合作伙伴均使用一张组合图；JPG/PNG/SVG；游戏合作平台建议1125×744；充值合作伙伴建议1125×195；单张图片不超过2M；按比例缩放 |
| 图片校验 | 所有上传图片统一限制不超过2M，等于2M允许上传，超过2M拒绝并保留原草稿；建议尺寸不作为强制拦截条件；自定义必须上传可解码图片；不合并或新增实际支付渠道/游戏接入关系 |
| 文案 | 纯文本，保留换行，演示上限3000字；允许清空并隐藏文案区域 |
| 媒体新增/编辑 | 媒体类型、图标、链接必填；备注可选；新增时必须上传图标，不提供内置图标选择；编辑时回显已上传图标，未替换则保留；上传图标建议114×114，图片不超过2M；链接允许HTTPS或#；#表示仅展示 |
| 媒体类型唯一性 | 新增和编辑均不允许与其他记录的媒体类型重复；原型按去除首尾空格且不区分大小写校验，编辑排除当前记录 |
| 媒体弹窗 | 按顺序展示媒体类型输入框、媒体链接输入框、图标预览及上传图片按钮、备注多行文本框；底部“确定”保存，右上角关闭不保存 |
| 媒体删除 | 二次确认；取消不变；确认后客户端移除；列表为空则隐藏图标区域 |
| 媒体排序 | 按新增顺序展示，编辑保持原位置，删除后序号重排；本期不擅自加入启停/拖动排序 |
| 外链 | 有效HTTPS在新页打开；演示数据全部为#，正式链接待提供 |
| 持久化 | 同一页面内联动；通过同源HTTP打开时支持跨标签页同步；直接双击文件时跨页存储因浏览器而异，以后台内嵌预览为准；存储失败提示，不冒充成功 |


## 状态与闭环
| 状态/操作 | 后台 | 客户端 |
|---|---|---|
| 已保存 → 编辑 | 进入未保存状态 | 保持原值 |
| 草稿 → 切换栏目或刷新页面 | 不保存草稿，不弹出确认提示，重新读取已保存配置 | 不变 |
| 草稿 → 校验失败 | 显示原因，保留草稿 | 不变 |
| 草稿 → 保存成功 | 更新配置 | 刷新已保存内容 |
| 草稿 → 存储失败 | 错误提示，保留草稿 | 不变 |
| 删除 → 取消/确认 | 保留/删除对应行 | 保留/移除对应图标 |

## 权限地图
| 模块/页面 | 权限项 | 作用范围 | 无权限表现 |
|---|---|---|---|
| 系统管理/站点显示配置 | 查看 | 四项配置 | 页面是否隐藏待确认 |

| 用户日志（新） | 查看日志 | 授权操作记录 | 数据范围待确认 |

## 客户端更新与缓存建议
保存成功后，客户端接收接口更新通知，获取并更新新内容，更新完成后写入客户端本地缓存。此项仅为实现建议；本地原型仅演示保存联动，不代表已接入真实通知接口。
