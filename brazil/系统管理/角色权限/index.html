角色管理－会员管理接口权限 PRD

一、已确认内容

在「会员管理－会员列表」及「会员管理－账变记录」下，均新增“接口权限：查询”与“接口权限：查询 UID 详情”。

权限项授权后规则未授权后规则
接口权限：查询打开页面时加载全局列表；允许使用页面既有全局查询条件。不加载全局列表，展示空数据；全局查询不可用。
接口权限：查询 UID 详情允许输入单个指定会员 ID 精确查询。指定会员 ID 查询不可用。

二、权限地图

权限模块页面权限项可操作范围无权限展示
会员管理会员列表接口权限：查询加载全局列表及使用全局查询条件空列表；全局查询不可用
会员管理会员列表接口权限：查询 UID 详情单个指定会员 ID 精确查询会员 ID 查询控件不可用
会员管理账变记录接口权限：查询加载全局列表及使用全局查询条件空列表；全局查询不可用
会员管理账变记录接口权限：查询 UID 详情单个指定会员 ID 精确查询会员 ID 查询控件不可用

三、规则闭环

  1. 角色编辑页勾选权限并确认保存后，子账号下次进入对应页面时按最新权限生效。
  2. 两项权限独立控制：仅有“查询”可进行全局查询；仅有“查询 UID 详情”不加载全局列表，但可按指定会员 ID 精确查询。
  3. UID 精确查询不得传入账号、日期、账变类型、分页、空 ID 或批量 ID 参数；未授权“查询”时不得通过缓存、翻页或 UID 接口取得全局列表。

四、待确认事项

“暂时列表信息”的数据范围、角色权限变更对已登录子账号的即时生效方式，以及全局查询可使用的具体筛选字段，尚待技术与业务确认。

五、建议方案

角色权限变更记录子账号操作日志：角色名称、页面、权限项、变更前/后值、操作人、操作时间、IP 与保存结果；后端接口需同步鉴权，不以页面置灰作为唯一限制。

PRD 补充：查询权限总开关规则

已确认：未配置“接口权限：查询”时，会员列表与账变记录均不得发起任何数据查询。无论选择会员 ID、账号、日期、账变类型或其他查询条件，均不得返回数据，页面始终展示空列表。

权限组合页面首屏查询条件与查询动作
未配置“接口权限：查询”空列表所有查询条件及查询按钮不可用。
已配置“查询”，未配置“查询 UID 详情”可加载列表会员 ID / 账号查询不可用；其他已授权查询条件的具体范围待确认。
同时配置两项权限可加载列表允许按会员 ID / 账号查询。

接口鉴权要求

“接口权限：查询”为全部查询接口的总开关，后端须在接口层拦截未授权请求；前端置灰、空列表仅为展示控制，不能作为唯一权限限制。

PRD 更新：UID 查询权限独立规则

本节为最新确认规则，覆盖此前“未配置接口权限：查询时，所有查询条件均不可用”的描述。

权限组合页面打开时可执行查询限制
仅勾选“接口权限：查询 UID 详情”不加载全局列表，展示空列表。可输入指定会员 ID 查询对应会员数据。不可进行全局查询；账号、日期、账变类型等其他条件不允许查询。
仅勾选“接口权限：查询”加载全局列表。不支持按指定会员 ID 查询。会员 ID 查询控件不可用。
同时勾选两项权限加载全局列表。支持全局查询及指定会员 ID 查询。无。
两项均未勾选不加载全局列表，展示空列表。不可查询。全部查询控件不可用。

接口鉴权

“接口权限：查询 UID 详情”需提供仅按指定会员 ID 精确查询的独立接口权限；服务端须拒绝携带账号、日期、账变类型、分页或空会员 ID 的请求，避免以 UID 查询权限取得全局列表。

已确认内容

在「代理中心（无限极差）」下，为团队查询、每日数据、佣金来源、代理首页、直属查询新增“接口权限：查询”。

代理中心（无限极差）团队查询接口权限：查询允许加载及查询全局列表数据。不加载列表，展示空数据。
代理中心（无限极差）每日数据接口权限：查询允许加载及查询全局列表数据。不加载列表，展示空数据。
代理中心（无限极差）佣金来源接口权限：查询允许加载及查询全局列表数据。不加载列表，展示空数据。
代理中心（无限极差）代理首页接口权限：查询允许加载及查询全局列表数据。不加载列表，展示空数据。

该权限仅控制对应表的数据查询能力，不替代既有导出、详情、查看直属、每日数据等功能权限。后端应按页面/表的查询接口进行鉴权，未授权请求不得返回列表数据。

PRD 自检结论：会员管理查询权限最终口径

以下规则为「会员列表」与「账变记录」的唯一生效口径，覆盖页面中此前“UID 查询依赖全局查询”及“支持账号查询”的旧描述。

权限组合进入页面全局查询指定会员 ID 查询
两项均未勾选不加载列表，展示空数据。不可用。不可用。
仅勾选“接口权限：查询”加载全局列表。允许使用页面既有的全局查询条件。不可用。
仅勾选“接口权限：查询 UID 详情”不加载全局列表，展示空数据。不可用。允许输入指定会员 ID 进行精确查询；不支持账号、日期、账变类型、分页或空会员 ID。
两项均勾选加载全局列表。允许使用页面既有的全局查询条件。允许输入指定会员 ID 进行精确查询。

自检发现及修正

原描述问题修正后规则
“查询 UID 详情”未授权时写为“查询功能不可用”，容易被理解为全部查询不可用。该权限只控制指定会员 ID 精确查询；全局查询由“接口权限：查询”控制。
“查询 UID 详情”曾写为可按“会员 ID / 账号”查询。最新确认仅允许输入指定会员 ID；账号不属于 UID 查询权限范围。
旧规则未写清 UID 权限是否可独立使用。UID 权限可独立使用，但仅返回该指定会员 ID 的数据，不得据此获取全局列表。

服务端校验

全局查询接口校验“接口权限：查询”；UID 精确查询接口校验“接口权限：查询 UID 详情”。UID 接口必须校验会员 ID 为单个有效值，并拒绝账号、日期、账变类型、分页、空 ID 及批量 ID 参数。

会员管理查询权限 PRD（最终版）

一、权限联动规则

适用于「会员列表」与「账变记录」：勾选“接口权限：查询”时，系统自动勾选“接口权限：查询 UID 详情”，并固定该权限为已勾选、不可取消；未勾选“接口权限：查询”时，“接口权限：查询 UID 详情”可独立勾选或取消。

二、权限组合与页面效果

查询权限UID 查询权限页面打开时可执行操作
未勾选未勾选不加载全局列表，展示空数据。不可进行全局查询或指定会员 ID 查询。
未勾选已勾选（独立）不加载全局列表，展示空数据。仅可输入单个指定会员 ID 精确查询；不支持账号、日期、账变类型、分页、空 ID 或批量 ID。
已勾选自动勾选并固定加载全局列表。可使用全局查询条件，且可输入单个指定会员 ID 精确查询。

三、交互规则

  1. 勾选“查询”：自动选中并禁用 UID 查询权限复选框。
  2. 取消“查询”：UID 查询权限复选框恢复可操作，保留当前勾选状态，由操作人决定是否保留 UID 精确查询能力。
  3. 尝试单独取消被固定的 UID 查询权限：不可操作，不展示额外提示。
  4. 确认保存后，记录角色、页面、两项权限变更前/后值、操作人、时间、IP 与保存结果。

四、服务端鉴权

全局列表与全局查询接口校验“接口权限：查询”；指定会员 ID 精确查询接口校验“接口权限：查询 UID 详情”。当“查询”已授权时，服务端应同时视为具备 UID 查询权限；当仅具备 UID 查询权限时，接口仅允许单个有效会员 ID，不得返回全局列表。

角色管理－接口权限 PRD（最终版）

1. 权限范围

模块页面权限项
会员管理会员列表、账变记录接口权限：查询；接口权限：查询 UID 详情
代理中心（无限极差）团队查询、代理首页、直属查询接口权限：查询；接口权限：查询 UID 详情

每日数据、佣金来源不在本次新增查询权限范围。

2. 权限联动与查询范围

权限项配置规则查询范围
接口权限：查询勾选后自动勾选并锁定“查询 UID 详情”；取消后 UID 权限恢复可独立配置。加载全局列表，支持页面既有全局查询条件。
会员管理：查询 UID 详情可在未勾选“查询”时独立授予。仅支持单个指定会员 ID 精确查询。
代理中心：查询 UID 详情可在未勾选“查询”时独立授予。仅支持单个会员 ID或单个邀请 ID 精确查询。

3. 统计日期与页面展示

场景页面效果
仅具备代理 UID 查询权限不加载全局列表；会员 ID / 邀请 ID 与统计日期可用，其余全局条件置灰。
具备代理全局查询权限加载全局列表；统计日期与全部全局条件可用。
代理两项查询权限均无不加载列表；统计日期、UID 与全局条件均不可用。
会员管理无全局查询权限全局条件保留展示但置灰；如具备 UID 权限，指定会员 ID 查询可用。

4. 单查询按钮

页面仅保留一个“查询”按钮。填写 UID 时优先精确查询；未填写 UID 且具备全局查询权限时执行全局查询；仅具备 UID 权限但未填写 UID 时提示填写相应 ID；无任何查询权限时提示“暂无查询权限”，不发起接口请求。

5. 接口鉴权与日志

全局接口校验“接口权限：查询”；UID 接口校验“接口权限：查询 UID 详情”。UID 接口每次仅允许一个有效标识：会员管理仅会员 ID，代理中心为会员 ID或邀请 ID；不得以 UID 接口获取全局列表。保存角色权限时记录角色、页面、权限项、前后值、操作人、时间、IP、结果及失败原因。
