系统管理—账号管理：账号额度与备注配置
文档状态：需求整理，待评审。以下区分已确认内容、待确认事项和建议方案。

一、需求概述（已确认）

本次同时调整「创建账号」和「修改账号」两个弹窗，均须增加人工存入金额、人工优惠金额、批量人工优惠金额，不可仅修改编辑弹窗。编辑弹窗增加备注，列表同步展示备注。商户财务管理的人工优惠模块改为按当前后台操作者账号分配的人工优惠金额限制输入，不再直接读取安全设置配置。

业务逻辑：三个账号金额字段默认为 0，表示不做对应金额限制；配置为正数时，安全设置限定账号可分配额度，账号分配额度限定操作者实际输入金额。页面权限仍按原规则控制。

金额格式与配置校验（已确认）

三个账号金额字段默认均为 0，表示不做对应金额限制。输入框底纹提示为“填0表示不限制”；默认值显示时保留下方同文案说明。允许配置为 0 或最多两位小数的正数，统一显示两位小数：输入 50 显示 50.00，输入 50.5 显示 50.50，输入 0 显示 0.00。负数、非数字和超过两位小数的输入不符合格式规则。

建议方案（当前原型实现）：输入框失焦及点击保存时补齐小数；格式不正确时阻止保存并在字段下提示“请输入0或最多两位小数的正数”。不对超出两位的小数自动四舍五入。空值规则尚未确认，当前原型不增加必填限制。

配置上限校验（已确认）：账号金额为 0 时表示不限制，不触发该账号字段的配置上限校验。配置为正数时，分别读取安全设置中的对应全局单笔金额上限。点击保存时，若输入金额大于对应全局上限，阻止保存、保留当前弹窗与输入内容，并通过 toast 展示下列对应文案，括号内动态显示安全设置中对应的全局上限金额（统一保留两位小数）；等于上限不触发超限提示。

超限字段保存时 toast 提示
人工存入金额人工存入金额不可高于安全设置中的人工存入单笔金额（{对应全局上限金额}）。
人工优惠金额人工优惠金额不可高于安全设置中的人工优惠单笔金额（{对应全局上限金额}）。
批量人工优惠金额批量人工优惠金额不可高于安全设置中的批量人工优惠单笔金额（{对应全局上限金额}）。

提示示例：安全设置中的人工存入单笔金额为 888 时，超限保存提示“人工存入金额不可高于安全设置中的人工存入单笔金额（888.00）。”；888 为示例，实际展示读取到的对应配置金额。

原型演示：页面底部提供可调整的全局上限示例，初始均为 10000.00，仅用于交互演示，不代表线上金额；实际功能应读取安全设置中的全局配置。多个字段超限时，原型按字段顺序提示第一项。

创建账号功能说明（已确认，本次必须实现）

创建账号弹窗保留登录账号、登录密码、重置密码、复制密码、分配角色、取消与确认，新增人工存入金额、人工优惠金额、批量人工优惠金额。三个金额字段与编辑弹窗保持一致：默认 0.00 表示不限额；底纹提示“填0表示不限制”；支持最多两位小数并自动补齐；正数配置按对应安全设置全局上限校验，超限显示包含实际上限的 toast 并阻止创建。

默认值与提示三个金额字段默认显示0.00，表示不做对应金额限制；输入框底纹为“填0表示不限制”，提示图标说明与修改账号一致。

四、额度读取与业务流程（已确认）

环节处理规则
账号额度配置个人账号三个金额字段默认均为 0，表示不限制对应金额。配置为正数时，不得高于安全设置中对应的全局单笔金额，点击保存时校验。
人工优惠操作路径：商户财务管理 / 人工优惠。读取当前后台操作者账号分配的「人工优惠金额」：为 0 时不做该金额上限限制；为正数时作为输入金额上限，不再直接读取安全设置中的配置。
页面权限与超限操作者具备人工提存页面权限，且账号分配金额为正数时，输入金额大于该上限则提示“输入金额超出上限”。

人工优惠流程：操作者具备页面权限 → 输入金额 → 读取账号分配的人工优惠金额 → 为 0 时不做金额上限限制；为正数时比较输入金额，超出则提示“输入金额超出上限”。不限制金额仅指不应用该账号额度上限，其他业务规则仍适用。
