02 / 字段与汇总口径

字段口径
投注金额、有效投注、派彩金额、注单数对筛选范围内符合现有报表口径的记录汇总；沿用原有状态、时间字段及退款/撤单处理。
平台总输赢演示采用投注金额 − 派彩金额，正值绿色、负值红色；正式实现继承既有计算规则。
返奖率合计派彩 ÷ 合计投注 × 100%，不可对各站点返奖率取平均；分母为 0 显示“—”。
杀率合计平台总输赢 ÷ 合计投注 × 100%；分母为 0 显示“—”。
投注人数按统计范围去重会员；无跨站统一会员 ID 时使用“站点 ID + 会员 ID”。厂商之间、游戏之间可能重叠，合计人数重新去重，不能直接相加。
游戏性质 / 类型展示厂商在当前筛选范围内的属性；同厂商覆盖多个类型时显示“多类型”，不因此拆成多个厂商行。

03 / 条件继承与返回

L0 → L1：保存 L0 已查询条件、排序和页码，追加所选厂商并锁定。L1 可在继承范围内缩小厅主、站点、类型、性质和日期范围；切换厂商需返回 L0。

L1 → L2：保存 L1 已查询条件，追加所选站点及归属厅主。原有“地区查询”即站点，原型将其与厂商设为只读，防止偏离下钻范围。重置仅清空游戏名称。

L2 → L3：追加选中游戏；单日默认继承日期范围的开始日，可切换范围内日期。重置回开始日。关闭弹窗逐层返回，上层筛选与结果保留。

返回 L0 恢复进入 L1 之前的查询状态；L1 的重置回进入时的条件，不解锁厂商。查询按“查询”按钮生效，未提交的输入不影响导出或下钻。

04 / 展示与操作

保留现有蓝色操作、深色导航、白色表格和输赢配色。列表支持排序、分页、空态、重置和 CSV 演示导出；合计为全部查询结果，不是当前页。正式导出沿用现有导出机制，范围与当前层级一致。

原型边界
已通过云桌面查看 L1 现有表、L2 游戏报表和 L3 投注分段。L3 当时为空，因此分段区间与数据均为演示，并非已确认线上配置。所有页面使用同一组虚构投注明细计算，未接入后台。演示数据日期：2026-11-22 至 2026-11-28。

05 / 开发对齐项

以现有平台 ID 作为“厂商”分组键，不将 MyPG 与其他 PG 平台自动合并。沿用现有权限、数据可见范围、币种和 UTC-3 日期边界；不同币种不能直接求和。需对齐统一会员标识、既有结算/撤单口径及 L3 分段配置。
