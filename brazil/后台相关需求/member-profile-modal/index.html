会员列表 - 点击会员ID - 打开个人资料弹窗；本说明仅记录当前已确认交互。
已确认交互
已确认内容
入口 会员列表点击会员ID后，打开个人资料弹窗；弹窗关闭后保留在当前页面。
会员列表 会员列表页面内容、查询条件、批量操作、新增、导出和表格字段按截图还原；点击左侧“会员列表”回到列表首页。
个人资料 展示会员账号、会员ID、注册方式、所属地区、所属商户、账号状态、上级代理、VIP等级、会员层级、账户余额、充值提现、投注输赢、登录注册信息等。
底部复用模块 个人资料弹窗底部补充“登录信息”和“开启游戏”模块，复用已有会员详情页的登录信息列表与开启游戏配置现有功能；“开启游戏”勾选区、选择全部和保存按钮属于同一个功能模块组，需放在同一框内展示，避免开发误解为独立操作。
账户余额与资金入口
余额展示 账户余额保持显示数值：1010.52 （可用 900.52 + 余额宝 0 + 冻结 110）。余额查看权限统一在“系统管理-账号管理”中为后台操作人员授权。
刷新 点击后更新玩家余额数据，并展示“操作成功”反馈。
人工提存 关闭个人资料弹窗，打开人工提存页，自动带入当前会员ID，并展示会员ID有效性检查通过。
帐变记录 关闭个人资料弹窗，打开帐变记录页，默认带入当前会员ID，搜索日期为今日。
页面跳转规则
充值记录打开帐变记录页；会员ID自动带入当前会员；帐变类型=存款；账变名称=全部；搜索日期=今日。
提现记录打开帐变记录页；会员ID自动带入当前会员；帐变类型=取款；账变名称=全部；搜索日期=今日。
优惠记录打开帐变记录页；会员ID自动带入当前会员；帐变类型=活动优惠；账变名称=全部；搜索日期=今日，并展示活动优惠相关数据。
稽核详情打开稽核管理页；自动带入会员ID查询，并展示对应稽核结果。
投注记录打开游戏对局记录页；带入会员ID进行查找；投注时间和结算时间默认今日，展示今日数据。
体育投注记录按钮置灰，功能未开放，暂不响应业务跳转。
会员列表从人工提存、帐变记录、稽核管理、游戏对局记录等页面点击会员列表，返回会员列表首页。
弹窗与按钮交互
  • 加入黑名单：后台状态、按钮切换和客户端登录影响按“黑名单与禁止投注影响范围”执行。
  • 禁止投注：后台按钮切换和客户端游戏场馆/下注拦截按“黑名单与禁止投注影响范围”执行。
  • 踢到大厅：后台反馈、客户端登出影响和游戏中会员处理按“踢到大厅影响范围”执行。
  • 修改密码：打开“修改会员登录密码”弹窗；输入时即时校验，规则为6-16位非空格字符；保存不需要二次确认，成功后强制玩家重新登录。
  • 修改资金密码：打开“修改会员资金密码”弹窗；输入时即时校验，规则为6位阿拉伯数字；保存不需要二次确认，成功后不强制玩家重新登录。
  • 重置资金密码：先弹出确认提示；确认后展示操作成功，会员需在客户端重新设置资金密码，不强制玩家重新登录。
  • 代理拉线：打开代理拉线弹窗；需先查询目标会员ID，确认不会出现闭环才可保存；保存前展示风险提示。
  • 真实姓名-实名关联：打开关系查询弹窗；检索库表读取PIX同名（真实姓名相同）的会员信息并展示。
  • 最后登录-IP关联 / 设备关联：打开关系查询弹窗；分别按最后登录IP、最后登录设备检索同条件会员信息并展示。
  • 注册IP-IP关联 / 设备关联：打开关系查询弹窗；分别按注册IP、注册设备检索同条件会员信息并展示。
  • 注册指纹ID：本期不做指纹ID识别，按竞品口径固定显示“无”，不提供指纹ID关联查询入口。
  • 修改层级：打开会员层级弹窗；选择目标层级后保存，提示手动调整后会员固定到该层级不会增长。
  • 提现账号修改：点击“提现账号-修改”打开提现账户弹窗；弹窗内展示PIX分组，本期仅支持真实姓名、CPF字段编辑，CNPJ、EVP、手机号、邮箱字段保留展示但置灰不可编辑，并在弹窗中说明“以下字段本期不做”；保存后回写个人资料展示；原型示例切换按钮放在外层“修改”按钮后方。
  • 修改手机号：本版本不支持编辑；因无对应权限，按钮置灰不可点击。
  • 修改邮箱：本期不做；按钮置灰不可点击，不进入弹窗、不发起接口。
  • 解绑Telegram：本期不做；按钮置灰不可点击，不进入确认弹窗、不发起解绑接口。
  • 备注-修改：打开备注弹窗，默认带入当前备注内容；最多输入200个字符，输入时展示字数统计，支持一键清空；保存后回写个人资料“备注”字段并提示操作成功。
黑名单与禁止投注影响范围
加入黑名单-后台 点击“加入黑名单”后，会员账号状态变为“正式 / 黑名单”，按钮切换为“移出黑名单”，页面展示“操作成功”；再次点击“移出黑名单”后，会员账号状态恢复为“正式 / 正常”，按钮切换回“加入黑名单”，页面展示“操作成功”。
加入黑名单-客户端 会员被加入黑名单后，已登录但未进入游戏的玩家会被踢出登录状态，且无法再次完成登录；客户端不展示具体错误提示。正在游戏中的玩家不受当前游戏进程影响，退出游戏后自动登出，且不可再次登录。
禁止投注-后台 点击“禁止投注”后，按钮切换为“允许投注”，页面展示“操作成功”；再次点击“允许投注”后，恢复会员投注权限，按钮切换回“禁止投注”，页面展示“操作成功”。
禁止投注-客户端 会员被禁止投注后，玩家点击打开对应游戏场馆时，客户端或游戏启动链路需拦截并返回错误提示，提示口径为“禁止下注”或“游戏启动失效”。如三方接口文档定义了对应的禁止下注错误码，则传递该错误码给三方；如三方未定义对应错误码，则传递其他可阻断下注/启动的错误码，确保玩家无法进入下注流程或完成下注。
状态关系 加入黑名单主要影响账号登录资格；禁止投注主要影响游戏场馆启动/下注链路，两者是不同控制项，可独立配置。
踢到大厅影响范围
踢到大厅-后台 在线会员点击“踢到大厅”后，后台展示“操作成功”；离线会员或会话已失效时，后台展示“操作失败”，不改变会员状态。
踢到大厅-客户端 在线会员被踢到大厅后，玩家从登录状态被踢出并回到登录页，客户端提示：O login expirou. Por favor, faça o login novamente。
游戏中会员处理 如果玩家正在游戏中，本次操作不影响当前游戏进程；玩家退出游戏后自动登出客户端，并回到登录页。
状态关系 “踢到大厅”仅处理当前登录会话，不改变账号状态、黑名单状态或投注权限；玩家重新登录能力仍取决于账号状态、黑名单状态、登录权限等规则。
账户安全类操作
修改登录密码 不需要二次确认；保存成功后强制玩家重新登录；操作结果记录到“子账号操作日志（新）”。
修改资金密码 不需要二次确认；保存成功后不强制玩家重新登录；操作结果记录到“子账号操作日志（新）”。
重设资金密码 保留确认弹窗；确认成功后会员需在客户端重新设置资金密码，不强制玩家重新登录；操作结果记录到“子账号操作日志（新）”。
失败与权限 失败文案沿用“接口异常与反馈规则”；无对应权限时按权限分配结果置灰对应功能按钮，不进入弹窗、不发起接口。
数据审计与操作留痕
记录表 会员个人资料弹窗内的关键操作统一记录到“子账号操作日志（新）”，作为操作审核依据和后台留痕。
记录操作 加入/移出黑名单、禁止/允许投注、修改层级、修改登录密码、修改资金密码、重设资金密码、备注修改、提现账号修改、代理拉线均需记录；修改邮箱、解绑Telegram本期不做，暂不产生操作日志。
记录字段 需记录操作人、操作人子账号ID、被操作会员ID、操作类型、操作前值、操作后值、操作时间、操作IP、操作结果、失败原因（如有）。
审计规则 操作成功必须记录成功日志；操作失败、权限不足、接口异常等未完成操作也需记录失败日志，用于后续审核和问题追溯。
提现账号展示规则
未绑定 个人资料“提现账号”字段显示“未绑定”；右侧保留“修改”按钮，并在按钮后方显示（原型示例：未绑定/已绑定）状态切换。
已绑定 个人资料“提现账号”字段显示PIX账户信息，格式为：PIX:
CPF：83337377068 手机号：51993351812 真实姓名：Francisco。
弹窗字段 真实姓名用于收款人身份识别；CPF为个人税号，本期支持编辑并保存。CNPJ为企业税号、EVP为PIX随机密钥、手机号和邮箱可作为PIX收款标识，但本期不做，弹窗内置灰展示，不允许输入和保存。
登录IP字段口径
登录IP 用于登录记录明细，记录每一次登录行为对应的IP，可用于登录日志追踪、历史登录明细和异常登录回溯。
最后登录IP 用于会员资料快照，保存会员最近一次成功登录的IP，适合作为个人资料展示和“最后登录-IP关联”的检索条件。
IP归属地解析 个人资料展示时，系统根据原始IP调用IP库解析国家、城市、运营商，并组合展示为：2804:b4:bc93:3400:19f:2d28:5150:68d6（国家:巴西，城市:帕苏斯，运营商:AS28294 GIGA MAIS FIBRA TELECOMUNICACOES S.A.）。
存储建议 建议两个字段分开存储：登录IP保留在登录明细表，最后登录IP保留在会员主表或会员扩展表；最后登录IP由最新登录成功记录同步更新。
关系查询 关系查询结果列表补充“最后登录IP”字段，并支持横向滑动展示完整数据，避免字段过多时压缩导致信息缺失。
注册指纹ID 本期不做指纹ID识别；个人资料中该字段固定显示“无”，不存储、不检索、不展示同指纹注册人数。
关系查询规则
实名关联 入口位于“真实姓名”行；对应“同会员真实姓名人数”；点击后打开关系查询弹窗，按当前会员PIX真实姓名检索真实姓名相同的会员。
最后登录-IP关联 入口位于“最后登录”行；按当前会员最后登录IP字段检索同IP会员。
最后登录-设备关联 入口位于“最后登录”行；按当前会员最后登录设备号检索同设备会员。
注册IP-IP关联 入口位于“注册IP”行；按当前会员注册IP字段检索同注册IP会员。
注册IP-设备关联 入口位于“注册IP”行；按当前会员注册设备号检索同设备会员。
注册指纹ID 本期不做指纹ID识别，个人资料固定显示“无”；不提供指纹ID关联查询入口，不进行指纹ID检索。
数据范围 弹窗打开时，先根据入口关联字段生成基础结果集，例如实名关联、最后登录IP关联、注册IP关联、设备关联等；弹窗内筛选项只作用于该基础结果集，不重新扩大查询范围。
会员ID筛选 在关系查询弹窗中输入会员ID后，仅在当前关系查询结果表内进行二次筛选，展示会员ID匹配的玩家数据；不改变原关系查询入口的检索条件。
渠道筛选 在关系查询弹窗中输入渠道后，仅在当前关系查询结果表内进行二次筛选，展示渠道匹配的玩家数据；不改变原关系查询入口的检索条件。
地区/商户筛选 地区默认带入当前会员所属地区，商户默认带入当前会员所属商户，均可手动调整；用于筛选当前关系查询结果表中对应地区、商户的玩家。
查询按钮 点击“查询”后，按会员ID、渠道、地区、商户对当前关系查询结果进行组合筛选；筛选为空时，表格区域展示“暂无数据”。
列表字段 关系查询弹窗列表字段固定一致：会员ID、真实姓名、地区、商户、渠道、最后登录时间、最后登录IP、登录次数、注册IP、有效投注、游戏输赢、充值总额、提现总额。
滚动与分页 弹窗内列表支持横向滑动和上下滑动，保证字段完整展示；底部展示分页信息、当前页和每页条数，默认50条/页。
输赢总览趋势图说明
  • 横轴为局数，固定展示近100局；按投注时间排序，每一个点代表一局，鼠标移入局数位置时，浮层顶部数字表示当前第几局，例如21、22。
  • 纵轴为当日输赢，数值从负数到正数；输赢口径为单局输赢，点越高表示该局盈利越高，低于0表示该局亏损。
  • 盈利峰值是指会员在某个统计时间段内盈利达到的最高值，例如今日、昨日、本周、本月、上月等时间段；如会员今日最高盈利5万，则今日盈利峰值显示5万。
  • 近100局不跨场馆合并排序，按单局展示；每个局数模拟一个或多个游戏场馆的输赢。“输赢总览”表示该局所有游戏场馆合计值，PG、PP_OneAPI、Tada、CQ9、EvoPlay等表示单个游戏场馆值。
  • 场馆列表来源为：商户游戏管理 - 平台管理页。
  • 浮层按场馆展示当前局数下的输赢值；示例中第21局“输赢总览=353.6、PG=353.6、其他场馆=0”，表示该峰值来自PG场馆。
  • 底部场馆图例默认全选；点击某个场馆后，该场馆按钮置灰，对应趋势线和浮层行同步隐藏，其他已选场馆数据保持展示；再次点击恢复高亮并重新作用于趋势图。取消勾选单个场馆后，“输赢总览”仍包含该场馆数据，不随场馆勾选状态扣减。
输赢统计明细跳转

  • 跳转时自动带入当前行会员ID和当前输赢统计查询条件，用于查看该统计结果对应的游戏对局明细。

接口异常与反馈规则
建议口径 异常反馈统一按本表文案执行：成功和失败类操作使用顶部居中 Toast；查询无结果优先在表格区域展示“暂无数据”；会员不存在、网络异常、操作失败均不修改页面原有数据；无对应权限时功能按钮置灰不可点击。
操作成功 顶部居中展示 Toast：操作成功；成功后按当前操作同步更新页面状态或回写字段，例如黑名单状态、禁止投注状态、余额、备注、提现账号等。
操作失败 顶部居中展示 Toast：操作失败；页面停留在当前状态，不修改原有数据。
会员不存在 统一展示 Toast：会员不存在；适用于代理拉线目标会员查询、关系查询、跳转目标页自动带入会员ID查询等场景，不进入保存或下一步流程。
无操作权限 后台管理账号没有对应操作权限时，按权限分配结果将对应功能按钮置灰，不进入弹窗、不发起接口、不执行后续流程；已确认手机号修改、修改邮箱、解绑Telegram在本版本置灰不可点击。
数据为空 关系查询、帐变记录、稽核管理、游戏对局记录、输赢统计等查询无结果时，表格区域展示“暂无数据”；查询条件保留，允许重新查询。
网络/接口异常 统一展示 Toast：网络异常，请稍后重试；页面停留在当前状态，不修改原有数据。
会员已离线 踢到大厅时如会员已离线或会话已失效，展示 Toast：操作失败；不展示客户端登录页模拟，不改变会员在线状态。
