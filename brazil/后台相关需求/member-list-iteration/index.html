本区域为当前交互原型同步的需求说明，便于评审时在同一个 HTML 文件内查看页面原型与规则口径。

1. 本次已确认需求

模块需求项已确认规则
会员列表新增字段列表新增「会员层级」字段，排序位置在「会员等级」之后。
会员列表字段覆盖原存款/提款相关字段区域调整为：首充金额、当日充值、当日提现、当日有效投注、当日输赢、当日优惠、历史充值、历史提现、历史有效投注、历史输赢、历史优惠、出款方式。
会员列表字段更名原「总资产」更名为「金币余额」。
会员列表搜索条件搜索区新增「金币」「会员层级」条件；金币支持两组指标区间组合查询，会员层级放在「会员等级」后方。
会员列表金币条件联动当两组金币条件同时被输入时，查询结果需同时满足两个条件后才展示。
会员列表代理ID查询当根据代理ID搜索时，查询结果应包含该代理ID对应的所有下级会员，以及下级会员的全部下级会员；下级关系按无限级递归处理，即该代理整条下级线内的会员结果均需展示。
会员列表时间字段拆分列表原合并展示的「注册日期 / 最后登录时间」拆分为两个独立字段：「注册日期」「最后登录时间」。
会员列表固定列列表左右滑动时，左侧勾选框、序号、会员ID 三列固定展示，不随横向滚动移出可视区域。
会员列表变更字段标识本次新增或改动的列表字段使用黄色字体或标识符突出，便于开发识别变更范围。
会员列表数据时区列表日期字段、当日统计及历史统计结果均按巴西 UTC-3 口径显示。
会员列表快捷筛选「今日新增 / 昨日新增 / 三日新增 / 七日新增」移动至列表左侧；「添加会员 / 导出 / 功能按钮」保持在右侧。
会员列表排序注册日期、最后登录时间、金币余额、首充金额、当日充值、当日提现、当日有效投注、当日输赢、当日优惠、历史充值、历史提现、历史有效投注、历史输赢、历史优惠支持升序/降序排序。
会员列表排序提示可排序字段表头默认展示上下箭头；鼠标悬停时展示黑色气泡提示「点击升序」；点击升序后，上箭头高亮，再次悬停提示「点击降序」；点击降序后，下箭头高亮，再次悬停提示「点击升序」。
批量操作操作入口列表新增勾选框和「批量操作」按钮。未勾选会员时点击，提示「请选择会员」。
批量操作选择范围不支持跨页勾选，仅支持对当前页已勾选会员进行批量操作；本期不支持按筛选结果全量批量操作。
会员列表导出导出为导出当前列表结果数据，与批量操作无关。
批量操作弹窗名称勾选会员后点击「批量操作」，打开「批量操作会员属性」弹窗。
批量操作操作类型操作类型支持：会员层级、出款方式、备注。
权限按钮状态本期无权限按钮统一置灰展示；后期如需隐藏按钮，作为独立迭代处理。
操作日志记录范围所有增删改操作均需加入「子账号操作日志（新）」表，并记录操作模块、操作页面、操作内容、操作前值、操作后值、操作对象会员ID、批量操作批次号、失败原因。

2. 搜索条件规则

字段规则
代理ID查询输入代理ID后，查询结果需展示该代理整条下级线内的会员。包含该代理ID对应的所有直接下级会员，以及直接下级会员的全部下级会员，并按无限级递归继续向下包含所有层级下级会员。
代理组合查询当代理ID条件与其他筛选条件同时存在时，先限定该代理整条下级线会员范围，再叠加其他筛选条件取交集。
金币条件支持两组金币条件；每组包含指标选择、最小值、最大值。
金币指标支持选择：全部、当日充值、首充金额、当日有效投注、当日输赢、当日优惠、历史充值、历史有效投注、历史输赢、历史优惠。
区间输入每组条件支持输入最小值和最大值，格式为「最小值 ~ 最大值」。
前端校验金币区间输入框仅允许输入数字和小数点，不允许输入字母、符号、中文等非数字字符。
区间完整性选择具体金币指标后，最小值和最大值都需要输入；仅输入最小值或仅输入最大值时不允许查询。
区间大小最小值必须小于等于最大值；若最小值大于最大值，提示「金额范围有误」，toast 显示 3 秒后消失。
小数格式输入完成后默认追加并展示两位小数；例如输入「50」自动调整为「50.00」。
参数口径查询和保存/传参时，金币区间值按两位小数格式传递。
双组查询当两组金币条件同时被输入时，查询结果需同时满足两组条件。
条件互斥两组金币条件不能重复选择同一个具体指标；例如条件 1 已选择「首充金额」时，条件 2 中「首充金额」置灰不可选，其他具体指标同理。「全部」不参与互斥。
全部指标选择「全部」时，不作为有效过滤条件，且该组最小值、最大值输入框不可输入并置灰；切回「全部」时需清空该组已输入区间。
具体指标选择具体金币指标后，该组最小值、最大值输入框恢复可输入。
会员层级条件搜索区在「会员等级」后方新增「会员层级」下拉筛选，支持选择全部、默认层级、10雷、20雷、50雷、100雷、200雷、500雷、1000雷；选择「全部」时不作为过滤条件，选择具体层级后仅展示该会员层级下的会员。

3. 批量操作规则

操作类型规则
批量范围不支持跨页勾选，仅支持对当前页已勾选会员进行批量操作；本期不支持按筛选结果全量批量操作。
导出关系导出为导出列表结果数据，与批量操作无关。
失败提示批量操作失败时不展示会员ID，只提示因系统原因导致操作失败的原因；如失败原因可获取，需同步展示失败原因。
操作反馈点击弹窗「确定」后不再展示二次确认弹窗，直接提交并反馈程序处理结果；toast 展示「操作成功」或「操作失败」，3 秒后自动消失。
会员层级选择「会员层级」时展示层级操作、层级、备注。层级操作支持「拉入层级」「移除层级」。选择「拉入层级」时，需选择目标层级。
人工移入固定规则玩家被人工移入指定会员层级后，该会员层级固定，不再随系统层级条件自动升降级或自动重算。
移除层级移除玩家当前已有会员层级，不区分该层级是否为自定义层级。移除后解除人工固定状态，并重新按系统会员层级规则计算应归属层级。
恢复判定口径移除现有层级后，需根据后台会员层级配置中当前生效的层级条件重新匹配系统层级；判定字段包含充值、有效投注、有效直属、直属有效充值金额。
结果口径重新计算后，玩家归属到满足当前系统规则的对应会员层级；如不满足任何更高层级条件，则归属到默认层级。
出款方式选择「出款方式」时展示出款方式下拉，支持「自动出款」「手动出款」。玩家注册时，默认出款方式为「自动出款」。
手动出款当玩家账号被调整为「手动出款」后，即使玩家提现金额低于免审核金额，也不会自动出款，需要财务人员介入处理；财务需选择对应出款方式和渠道后再处理出款。
备注选择「备注」时展示备注输入框；备注最多 500 字。
操作日志所有增删改操作均需加入「子账号操作日志（新）」表，并记录操作模块、操作页面、操作内容、操作前值、操作后值、操作对象会员ID、批量操作批次号、失败原因。
层级变更日志子账号操作日志列表需记录地区、商户、操作模块、操作页面、操作对象、操作内容、关键词、操作人、操作人类型、操作时间、操作IP。操作模块为「会员管理」；单会员操作页面为「修改层级」，批量操作页面为「批量更新用户层级」。
拉入层级日志单会员操作对象记录「移入会员层级 会员ID:{会员ID}」；批量操作对象记录「会员层级 移入」及批次/序号信息。单会员可直接展示「修改层级：修改前 → 修改后」；批量操作列表展示「查看详情」。
移除层级日志单会员操作对象记录「移出会员层级 会员ID:{会员ID}」；批量操作对象记录「会员层级 移出」及批次/序号信息。单会员可直接展示「修改层级：修改前 → 修改后」；批量操作列表展示「查看详情」。
详情字段点击「查看详情」后，弹窗按会员维度展示：序号、会员ID、层级id(修改前)、层级id(修改后)、customLevelId(修改前)、customLevelId(修改后)。
拉入字段口径层级id(修改前)记录玩家操作前系统/当前层级；层级id(修改后)记录人工拉入的目标层级；customLevelId(修改前/后)记录人工固定层级标识的变化，拉入后应写入目标层级对应的固定层级标识。
移除字段口径层级id(修改前)记录玩家移除前已有层级；层级id(修改后)记录按系统规则重算后的系统层级；customLevelId(修改前/后)记录人工固定/自定义层级标识移除前后变化，移除后为空或系统约定空值。

3.5 自动出款 / 手动出款与自动代付开关场景状态图

先看会员账号出款方式，再看自动代付开关，最后看自动代付条件。

1会员发起提现系统先读取会员账号的出款方式：自动出款 / 手动出款。
2判断会员出款方式手动出款直接走人工；自动出款才继续看自动代付开关。
3判断自动代付条件仅自动出款 + 自动代付开启时，继续判断免审、金额范围、渠道和余额。
人工进入人工处理的场景
  • 会员账号为手动出款。
  • 会员账号为自动出款，但自动代付开关关闭。
  • 自动代付开关开启，但免审不通过、金额不在范围、无可用渠道或渠道余额不足。
自动允许自动代付的场景
  • 会员账号为自动出款。
  • 后台自动代付开关开启。
  • 免审通过，提现金额在自动代付范围内。
  • 存在可用代付渠道，且渠道余额充足。
会员出款方式自动代付开关附加条件订单流向
手动出款开启 / 关闭不看免审金额，不触发自动代付进入人工处理；财务选择出款方式和渠道后处理。
自动出款关闭不触发自动代付进入出款审核 / 人工处理链路。
自动出款开启免审通过 + 金额在自动代付范围 + 存在可用渠道且余额充足系统自动锁定订单并发起自动代付。
自动出款开启免审不通过 / 金额不在范围 / 无可用渠道 / 渠道余额不足不自动打款，进入待审核出款订单，由财务人工处理。
