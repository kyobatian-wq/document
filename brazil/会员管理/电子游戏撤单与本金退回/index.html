游戏撤单与本金退回 · 一期交互原型

本期口径：未结算撤单保留 0 金额 T065 及三方业务时间；已结算撤单先以 T065 回滚已入账结算额，再以 T066 按三方通知取消金额退回本金。T066 不用于重新结算。后台与客户端的类型名称、业务时间、备注使用同一规则。页面为合成数据；零额/分次结算与并发处理为开发核对项。

规则说明

未结算撤单 T065

保留 0 金额帐变并记录三方取消时间。原余额不变，后续 T066 才增加本金。

已结算撤单 T065

三方只发取消通知。平台依据成功入账的 T064 流水回滚结算额 P；零额、分次入账与并发处理按需求文档的建议方案待开发核对。

本金退回 T066

按三方通知取消金额 C 退回。C 与原投注 A 不同时仍按 C 计算，并留差异供后续人工核对；已结算撤单须先回滚成功。

客户端与报表

类型、业务时间、备注与后台同源。下注与结算跨天时，报表归属结算日；取消视为结算事件，调整归属取消日。具体时区待开发核对。
