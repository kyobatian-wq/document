DD.GG 后台营销配置 PRD说明

版本：V1.0　适用范围：DD.GG 后台「系统设置 / 站点显示配置」与客户端首页营销展示区域

一、需求背景

为支持客户端首页固定营销位内容维护，DD.GG 后台需在「站点显示配置」中新增「营销配置」模块。运营可维护营销位名称、图片与点击跳转方式，客户端首页在主轮播图下方固定展示 3 个营销入口。

二、需求范围

  • 后台仅新增「营销配置」模块，不涉及其他站点显示配置项的新增或改造。
  • 营销配置为固定 3 条内容展示，不支持新增、删除、筛选查询。
  • 每条营销内容支持编辑，编辑弹窗由列表「操作」按钮触发。
  • 客户端首页展示区域固定为 3 个营销卡片，位置在首页主 banner 下方。

三、后台入口

项目 说明
菜单路径 系统管理 / 系统设置 / 站点显示配置 / 营销配置
同级模块 保留原有「轮播图」「跑马灯」，新增「营销配置」。本次不增加竞品后台中的其他配置模块。
地区与商户 沿用当前系统设置页顶部的地区、商户选择逻辑。

四、后台列表规则

字段 说明 规则
序号 展示营销位顺序 固定展示 1、2、3；客户端按该顺序从左到右展示。
名称 营销内容名称 用于后台识别与客户端卡片对应，不作为查询条件。
图片 营销位展示图 支持 JPG/PNG/SVG/webp 格式；建议尺寸 224 x 140。
最后操作时间 最近一次保存时间 编辑并保存后更新。
最后操作人 最近一次保存操作账号 编辑并保存后更新为当前后台操作人。
操作 编辑入口 点击编辑图标后弹出编辑弹窗。

五、编辑弹窗

字段 类型 说明
名称 输入框 编辑营销内容名称。
图片 上传组件 展示当前图片缩略图，支持重新上传；格式支持 JPG/PNG/SVG/webp，建议尺寸 224 x 140。
跳转方式 单选项 支持「内联链接」「跳转至链接」「不做跳转」三种方式。
活动名称 下拉框 当跳转方式为「内联链接」时展示。选项由「具体活动内联页」和「客户端主模块页」组成；具体活动内联页使用活动配置中的活动名称，客户端主模块页包括充值页、提现页、推广中心页、活动页、VIP页、兑换码页、首页。
跳转链接 输入框 当跳转方式为「跳转至链接」时展示，用于配置外部或指定 URL。
确定 按钮 保存当前营销配置；保存后关闭弹窗并刷新列表中的最后操作时间、最后操作人。

六、跳转规则

内联链接的活动下拉选项与轮播图配置保持同源，由「具体活动内联页」和「客户端主模块页」两部分组成。具体活动内联页展示活动配置中的可用活动；客户端主模块页固定置于列表底部，供营销卡片跳转至客户端主模块。

跳转方式 客户端点击效果
内联链接 点击营销卡片后，在客户端内跳转到后台选择的页面，例如充值页、活动页、VIP页等。
跳转至链接 点击营销卡片后，按配置的跳转链接打开对应页面。
不做跳转 点击营销卡片无跳转行为，仅作为展示图使用。

七、客户端展示规则

  • 展示位置：首页主 banner 下方，公告栏上方。
  • 展示数量：固定 3 个营销卡片。
  • 展示顺序：按后台列表序号 1、2、3 从左到右展示。
  • 展示内容：使用后台配置的图片；点击行为按后台配置的跳转方式执行。
  • 当图片加载失败时的兜底样式、是否需要默认图：待确认。

八、已确认规则

  • 名称字段客户端展示规则：按竞品所示，本期客户端不展示名称，仅展示营销图片内容。
  • 图片上传限制：单图文件大小不超过 5M。
  • 跳转至链接规则：本期不做扩充，不新增外部域名白名单等额外校验能力。
  • 编辑保存记录：编辑保存后需在数据库记录最后操作人、最后操作时间。
